# NBA Projections site

**Live site: [mcgahranjt.github.io/nba-projections-site](https://mcgahranjt.github.io/nba-projections-site/)**

Daily NBA projections for the 2026-27 season: tonight's games with model lines and totals, player stat projections with ranges, power rankings, and season odds from 10,000 simulated seasons.

This repository only holds the published page. `index.html` is rebuilt and pushed automatically twice a day by `build_site.py` in the [2026-27-NBA-Win-Projections](https://github.com/mcgahranjt/2026-27-NBA-Win-Projections) repository, which has the models, the methods and the backtest results. Edit the page there (`site_template.html`), not here.
